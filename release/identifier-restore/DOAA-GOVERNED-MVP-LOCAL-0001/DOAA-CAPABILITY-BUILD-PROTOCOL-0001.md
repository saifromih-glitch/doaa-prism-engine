# بروتوكول بناء قدرات Doaa المتتابعة

**المعرّف:** DOAA-CAPABILITY-BUILD-PROTOCOL-0001  
**الحالة:** معتمد كإطار تنفيذ  
**المرجع:** DOAA-FINAL-ROADMAP-0001

## القرار

سيُوسَّع Doaa بطريقة تراكمية مضبوطة. لا تُضاف قدرة مباشرة إلى النواة لمجرد أن النموذج اقترحها، ولا تُعتبر اللغة الطبيعية تفويضًا بالتنفيذ. كل قدرة جديدة تمر بدورة مستقلة:

| المرحلة | المخرج الإلزامي | شرط الانتقال |
|---|---|---|
| تعريف القدرة | وصف مغلق للنطاق والمدخلات والمخرجات والرفض | وضوح الحدود وعدم وجود صلاحية ذاتية |
| العقد والقرار | عقد JSON وADR ونموذج تهديد | مراجعة عدم التعارض مع الدستور |
| التنفيذ | منفذ حتمي مستقل عن النموذج | لا `exec` أو `eval` أو تشغيل كود مولد |
| الاختبار | حالات قبول ورفض وعدم مساس بالبيانات غير المستهدفة | نجاح الاختبارات القابلة لإعادة التشغيل |
| التكامل | ربط محدود بالنواة وسجل التدقيق والمراجعة البشرية | عدم تغيير المسارات المعتمدة دون دليل |
| القبول | تشغيل مجموعة الاختبارات الكاملة ومتحقق مستقل | إصدار مرحلي موثق |

## ترتيب القدرات المقترح

يُنفذ الترتيب التالي ما لم يصدر قرار جديد موثق يغير الأولوية:

| الترتيب | القدرة | سبب الأولوية | وضعها |
|---|---|---|---|
| 1 | توسيع DSL بتحويلات حتمية للبيانات | توسع مفيد منخفض المخاطر ويحافظ على النواة المحلية | التالية |
| 2 | طبقة تكامل محلي مقيدة | توحيد نقاط الاستدعاء دون منح صلاحية عامة | لاحقة |
| 3 | بحث خارجي اختياري ومقيد | قدرة عالية الحساسية تحتاج نموذج تهديد ومصادر مسموحة | لاحقة منفصلة |
| 4 | مستشار قدرة جديدة | يصف العجز ويقترح متطلبات فقط دون بناء أو تعديل | لاحقة منفصلة |
| 5 | مراقبة وصيانة قراءة فقط | كشف الانحراف دون إصلاح أو نشر تلقائي | لاحقة منفصلة |
| 6 | التكامل النهائي | بعد إغلاق القدرات السابقة واختبار التوافق | أخيرة |

## القدرة التالية: توسيع DSL

ستبدأ القدرة التالية بعمليتين أو ثلاث عمليات حتمية صغيرة فقط، مثل إزالة المحارف المحيطة أو توحيد حالة النص، بشرط أن يكون العمود محددًا صراحة وأن تنتج العملية نسخة جديدة من الملف. لا يُسمح بإضافة عملية عامة مثل `run_python` أو `execute_script` أو أي DSL قابل لتحميل تعليمات خارج العقد.

قبل التنفيذ الفعلي لهذه القدرة يجب إنشاء عقدها وقرارها واختباراتها. وفي حال فشل أي اختبار، يتوقف المسار ولا تُدمج القدرة في الإصدار.

## بوابة عدم الانحراف

يُوقف العمل ويُفتح قرار جديد إذا طلبت القدرة الشبكة، أو الأسرار، أو العمليات الفرعية، أو التثبيت، أو تعديل المصدر تلقائيًا، أو الجدولة، أو التنفيذ دون مراجعة بشرية. لا تُحل هذه الحالات بإضافات صغيرة أو بتفسير موسع للعقد الحالي.

## معيار النجاح العام

نجاح التوسع لا يُقاس بعدد القدرات المضافة، بل بقدرتها على تقديم فائدة محددة مع بقاء التنفيذ حتميًا، والرفض آمنًا، وسلطة النموذج `none`، والمراجعة البشرية إلزامية، وسجل التدقيق قابلًا للفحص، والملف الأصلي غير مستبدل.
