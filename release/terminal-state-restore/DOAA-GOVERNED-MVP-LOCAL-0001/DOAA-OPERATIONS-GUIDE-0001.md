# دليل تشغيل Doaa المحلي

## الغرض

يستخدم Doaa لتحويل CSV وXLSX ضمن عمليات محددة بعقود، مع فصل الاقتراح عن التنفيذ ومراجعة بشرية إلزامية.

## التشغيل

شغّل: `py -3 doaa_daily_ui.py` ثم اختر ملف الإدخال وملف الإخراج الجديد والعملية والعمود الصريح. اضغط تجهيز طلب للمراجعة. هذه الخطوة لا تنفذ شيئًا.

بعد المراجعة البشرية، يُشغّل المسار الحوْكمي المناسب. لا تكتب فوق الملف الأصلي. استخدم زر عرض تقرير التشغيل لقراءة نتيجة JSON وملخصها العربي.

## الضمانات التشغيلية

- سلطة النموذج: `none`.
- التنفيذ التلقائي: معطل.
- كود أو أمر صادر عن نموذج: مرفوض.
- نتائج البحث: قراءة واستشهاد فقط.
- اكتشاف تلف الحزمة: تنبيه فقط دون إصلاح ذاتي.
- كل مخرج يكتب في ملف جديد.

## حدود المسؤولية

نجاح الاختبارات لا يعني حصانة مطلقة من الفيروسات أو اختراق نظام التشغيل. يجب استخدام نسخ احتياطية وWindows Defender ومراجعة الملفات قبل فتحها.

## الترميز العربي

تدعم منفذات CSV مدخلات UTF-8 مع BOM، وتكتب مخرجات UTF-8 عادية. إذا كان الترميز غير معروف أو كان رأس العمود غير قابل للقراءة، يُحجب الطلب بدل التخمين. اجتاز اختبار CSV عربي مع BOM بنجاح، مع بقاء الأصل دون تغيير.

## الخطوة التالية

أي قدرة جديدة تحتاج عقدًا وقرارًا معماريًا ونموذج تهديد واختبارات قبول وتحديث manifest قبل دمجها.
