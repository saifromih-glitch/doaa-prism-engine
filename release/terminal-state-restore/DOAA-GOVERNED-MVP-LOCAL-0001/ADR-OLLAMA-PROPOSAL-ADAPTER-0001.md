# ADR-OLLAMA-PROPOSAL-ADAPTER-0001

## القرار

اعتماد محول محلي اختياري لـ Ollama يرسل prompt منظمًا إلى `http://localhost:<port>/api/generate` أو `http://127.0.0.1:<port>/api/generate`، ويعيد نص الاستجابة الخام فقط.

## الحدود

المحول لا يقرأ ملفات أو أسرارًا، ولا يستقبل مسارات كتابة أو أوامر أو كودًا، ولا يتصل بأي endpoint خارجي. لا يفسر الاستجابة ولا ينفذها ولا يمررها مباشرة إلى منفذ بيانات. الناتج غير موثوق ويجب أن يمر عبر وساطة النموذج والبوابة والمراجعة البشرية قبل أي تنفيذ.

## الفشل المغلق

يُحجب endpoint غير المحلي، والسلطة غير `none`، والهوية غير الصالحة، والprompt المحظور أو الطويل، والمهلة غير المسموحة، والاستجابة الكبيرة أو غير الصالحة، أو غياب النموذج المحلي.

## الدليل

نجحت ست حالات اختبار تشمل الاستجابة الخام، حجب endpoint الخارجي، حجب المحتوى التنفيذي، حجب السلطة، حجب المهلة، وحجب الاستجابة غير الصالحة. لا يثبت هذا جودة النموذج؛ بل يثبت حدود المحول فقط.

## خارج النطاق

لا جدولة، لا خدمة خلفية، لا تدريب، لا صيانة ذاتية، لا تنفيذ كود، لا اعتماد تلقائي، ولا اتصال سحابي.
