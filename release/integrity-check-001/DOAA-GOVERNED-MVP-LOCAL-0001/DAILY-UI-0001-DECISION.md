# واجهة الاستخدام اليومية — القرار 0001

## النتيجة

أضيفت واجهة محلية بسيطة باسم `doaa_daily_ui.py`. وظيفتها إعداد طلب JSON واضح للمراجعة فقط. لا تقرأ محتوى الملفات، ولا تستدعي النموذج، ولا تنفذ أمرًا أو تحويلًا خفيًا.

تطلب الواجهة ملف الإدخال، وملف الإخراج الجديد، والعملية، والعمود، واسم الورقة عند الحاجة. ثم تنشئ `doaa-request.json` بحالة `pending_user_review` و`execution_started: false`.

| الفحص | النتيجة |
|---|---|
| تجهيز طلب صالح | نجح |
| التأكيد البشري الافتراضي | `pending_user_review` |
| سلطة النموذج | `none` |
| تنفيذ خفي | غير موجود |
| إدخال وإخراج متساويان | حُجب |
| حقول ناقصة | حُجبت |
| قراءة محتوى الملفات | لا تحدث |

اجتاز اختبار الواجهة ثلاث حالات، وأُعيد بناء ZIP المحلي ليضم الواجهة والعقد والاختبار والدليل.

## طريقة التشغيل

من داخل مجلد الحزمة:

```powershell
$env:PYTHONUTF8='1'
py -3 .\doaa_daily_ui.py
```

بعد تجهيز الطلب، لا يعني إنشاء `doaa-request.json` أن العملية نُفذت. يجب أن يمر الطلب عبر المسار الحوْكمي ومراجعة بشرية صريحة قبل أي منفذ آمن.

## نطاق القرار

تم تحسين سهولة الاستخدام دون توسيع الصلاحيات. الإصدار يظل محليًا ومقيدًا، ولا يشمل التحديث الذاتي أو الشبكة أو البحث على الويب أو تشغيل Ollama تلقائيًا.
