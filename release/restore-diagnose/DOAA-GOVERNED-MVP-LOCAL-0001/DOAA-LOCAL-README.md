# Doaa Governed MVP — الحزمة المحلية

هذه الحزمة توحد تشغيل Doaa محليًا ضمن نطاق مقيد. نقطة الدخول هي `doaa_local.py`، وتبدأ بفحص التشخيص، ثم تختار منفذ CSV أو XLSX، وتكتب إلى ملف إخراج جديد فقط.

## التسلسل الحوْكمي

يجب أن يمر الطلب عبر الاقتراح والبوابة وسجل التدقيق والمراجعة البشرية قبل التنفيذ. لا يُقبل أي تنفيذ ما لم تكن الموافقة البشرية صريحة، وتكون بصمة الاقتراح صحيحة، ويكون مسار الإخراج جديدًا وتحت الجذر المعتمد.

> النموذج يقترح فقط. لا يملك النموذج أو نقطة الدخول سلطة تنفيذ مستقلة أو تحديثًا ذاتيًا.

## النطاق الحالي

| النوع | العنوان المدعوم | العملية |
|---|---|---|
| CSV | `phone` | إزالة المسافات والشرطات ASCII من العمود فقط |
| XLSX | `phone` أو `الهاتف` | إزالة المسافات والشرطات ASCII من ورقة وعمود محددين |
| CSV | عمود محدد صراحةً | توحيد runs الفراغات ASCII وحوافها في العمود فقط |

لا تُستنتج الأعمدة بالتخمين، ولا يُستبدل الإدخال، ولا تُعدّل أوراق أو أعمدة غير مستهدفة. عملية توحيد الفراغات لا تغيّر المسافات غير ASCII.

## التشغيل اليومي

يمكن تشغيل `doaa_daily_ui.py` لفتح واجهة محلية بسيطة. الواجهة تختار ملف الإدخال والإخراج والعملية والعمود، ثم تنشئ `doaa-request.json` للمراجعة. الواجهة لا تقرأ محتوى الملفات، ولا تستدعي النموذج، ولا تنفذ التحويل؛ التنفيذ يتم لاحقًا عبر المسار الحوْكمي فقط.

```powershell
$env:PYTHONUTF8='1'
py -3 .\\doaa_daily_ui.py
```

## التشغيل البرمجي

يُمرر طلب JSON واحد إلى نقطة الدخول:

```powershell
$env:PYTHONUTF8='1'
Get-Content -Raw -Encoding UTF8 .\request.json | py -3 .\doaa_local.py
```

يجب أن يحتوي الطلب على `proposal` و`human_review` و`input_path` و`output_path` و`allowed_root`. لملفات XLSX يجب إضافة `worksheet` باسم الورقة المطلوب تشغيلها.

## حالات الحجب

تتوقف الحزمة عند فشل التشخيص، أو اختلاف البصمة، أو غياب الموافقة البشرية، أو وجود ملف إخراج مسبق، أو محاولة الكتابة خارج الجذر، أو غياب العنوان المطلوب، أو امتداد غير مدعوم.

## الاسترجاع الحتمي قبل النموذج

يمكن لطبقة الاسترجاع فحص سجل الخوارزميات بالتطابق التام في العملية والعمود والورقة وإصدار DSL. عند `cache_hit` لا يُستدعى النموذج، وعند `cache_miss` لا يحدث تخمين أو تنفيذ تلقائي.

## حدود الإصدار

هذه أداة محلية مقيدة وليست وكيلًا مستقلًا. لا تشمل التحديث الذاتي، أو البحث على الويب، أو الوصول إلى الأسرار، أو الشبكة، أو تثبيت الحزم، أو تشغيل النموذج تلقائيًا. كل عملية جديدة تحتاج عقدًا واختبارات مستقلة.
