# تقرير دورة دعاء — DOAA-CYCLE-REPORT-0001

## الحالة

أُغلقت دورة التوسع المحافظ الحالية بعد اعتماد مسار تطبيع Unicode المحدود لملفات CSV وXLSX وربطه بالتدفق المحلي والمسجل، وإضافة وسيط Ollama محلي يعيد اقتراحًا خامًا غير تنفيذي، وواجهة مراجعة بشرية تمرر القبول إلى البوابة فقط.

## المبدأ الحاكم

> النماذج تقترح، وPython ينفذ — ولا يملك النموذج سلطة تنفيذ أو تعديل أو نشر.

كل تنفيذ يتطلب عقدًا محددًا، اقتراحًا مطابقًا، بوابة قبول، مراجعة بشرية صريحة، hash للاقتراح، hash للمعاينة، وسجل تدقيق. التنفيذ يكتب مخرجًا جديدًا ولا يعدل المصدر.

## القدرات المعتمدة

| القدرة | النطاق | الحالة |
|---|---|---|
| إزالة فواصل الهاتف ASCII | CSV/XLSX حسب العقد | معتمدة |
| توحيد المسافات ASCII | CSV/XLSX حسب العقد | معتمدة |
| حذف المسافات ASCII الطرفية | CSV/XLSX حسب العقد | معتمدة |
| تحويل Tab إلى مسافة ASCII | CSV/XLSX حسب العقد | معتمدة |

| طبقة التكامل المحلي | envelope منظم، تصنيف فقط، in-process | معتمدة كوسيط محكوم |
| وسيط Ollama المحلي | endpoint محلي فقط، نص خام غير موثوق، فشل مغلق | معتمد كوسيط اقتراح |

## الحدود الصريحة

لا يوجد تطبيع Unicode عام. لا تُقبل محارف أخرى ضمن القدرة الحالية. لا ينفذ Doaa كودًا مولدًا من النموذج، ولا يشغل shell أو subprocess، ولا يستخدم الشبكة أو الأسرار أو التثبيت أو النشر. لا توجد صيانة ذاتية أو ترقية تلقائية للمصدر أو العقود أو الاختبارات.

## الأدلة

نجحت مجموعة القبول الكامل الأخيرة في **57 اختبارًا**، منها ست حالات لوسيط Ollama المحلي، وعشر حالات لطبقة التكامل المحلي، واختبار end-to-end لمسار XLSX Unicode. شملت الأدلة اختبارًا مستقلًا لمسار XLSX Unicode، واختبار end-to-end للبوابة والتدقيق والمراجعة البشرية والتنفيذ والتسجيل، واختبارات hash المعاينة، واختبارات الحجب، واختبار envelope للتكامل المحلي، واختبار الاستعادة من حزمة ZIP.

## المخاطر المتبقية

تظل جودة اقتراح النموذج احتمالية، ولذلك لا يُعتمد أي اقتراح لمجرد سلامة صياغته. كما أن دعم OpenXML يظل محدودًا بالعقود والمنفذات المختبرة، ولا يمثل ضمانًا شاملًا لكل تنسيقات Excel أو كل خصائص المصنفات المعقدة.

## المرحلة التالية المقترحة

قبل أي قدرة جديدة، تُراجع العقود الحالية وتُحدد فجوة واحدة فقط. أي توسعة تتطلب ADR وعقدًا واختبار قبول وفاحصًا ثابتًا وربطًا بالتدفق وسجلًا في manifest، ثم قبولًا كاملًا جديدًا. لا يُفتح مسار بناء ذاتي أو اتصال خارجي ضمن هذه الدورة.
