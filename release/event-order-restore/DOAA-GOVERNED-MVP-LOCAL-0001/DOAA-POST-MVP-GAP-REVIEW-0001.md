# مراجعة فجوات ما بعد الـMVP — DOAA-POST-MVP-GAP-REVIEW-0001

## النتيجة المختصرة

النواة المحكومة مكتملة. طبقة التكامل المحلي موجودة كوسيط تصنيف in-process، وطبقة وساطة النموذج موجودة كفاحص envelope يرفض المحتوى التنفيذي. الفجوة العملية المتبقية هي **محوّل Ollama محلي اختياري** يرسل طلبًا منظمًا ويستقبل اقتراحًا خامًا بوصفه غير موثوق، دون أن يتولى التصنيف أو المراجعة أو التنفيذ.

## الحالة الفعلية

| المجال | الموجود | الفجوة |
|---|---|---|
| التكامل المحلي | envelope منظم، authority=`none`، حجب shell والكود والكتابة | لا توجد فجوة أمان لازمة؛ يلزم فقط اختبار استمرار |
| وساطة النموذج | فحص هوية وبنية وحجب المحتوى التنفيذي | يحتاج adapter اتصال محلي اختياريًا بمهلة وفشل مغلق |
| Ollama | عقود وسجلات تشخيص واختبارات smoke سابقة | لا يُفترض توفر الخدمة؛ يجب أن يكون الغياب نتيجة محكومة لا فشلًا مفتوحًا |
| البوابة | تحقق حتمي من العملية والعمود والمعاملات | لا تُعدّل؛ تستقبل الناتج غير الموثوق فقط |
| التنفيذ | منفذات CSV/XLSX حتمية | لا تُربط مباشرة بمحوّل Ollama |
| الصيانة | تقارير readonly | لا إصلاح أو تحديث ذاتي |

## قرار البناء التالي

بناء adapter محلي محدود للاتصال بـ Ollama، بعقد مستقل. يقبل فقط `message_id` و`model_id` و`prompt` المنظم، ويعيد نص الاستجابة الخام أو نتيجة حجب. لا يسمح بإرسال مسارات ملفات أو أسرار أو أوامر أو كود. لا ينفذ JSON الناتج، ولا يمرر الناتج للتنفيذ قبل البوابة والمراجعة البشرية.

## شروط القبول

يجب أن تغطي الاختبارات: endpoint غير صالح، مهلة الاتصال، استجابة غير JSON أو كبيرة، مفاتيح محظورة، authority غير صحيحة، نجاح استجابة خام، وعدم وجود أي تنفيذ أو كتابة أو شبكة خارج الطلب المحلي المقصود. لا يُعد نجاح smoke دليلًا على صحة النموذج أو جودة الاقتراح؛ بل يثبت فقط حدود الوسيط.

## خارج النطاق

لا جدولة، لا خدمة خلفية، لا نشر، لا استدعاء شبكة خارجية، لا تدريب، لا تعديل ذاتي، ولا اعتماد تلقائي لاقتراح النموذج. أي توسعة لهذه الحدود تتطلب قرارًا معماريًا منفصلًا.
