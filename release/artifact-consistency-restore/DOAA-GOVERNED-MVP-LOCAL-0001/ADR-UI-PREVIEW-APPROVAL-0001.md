# ADR: ربط المعاينة بالموافقة

## القرار

لا يُجهز طلب من الواجهة إلا بعد معاينة ناجحة. تُحفظ قيمة `preview_input_sha256` داخل طلب الموافقة، ويعيد المنفذ الحجب إذا تغيّر المصدر قبل التنفيذ.

## الحدود

الواجهة لا تنفذ عمليات، ولا تستدعي شبكة أو نموذجًا، ولا تعدل الأصل. زر المعاينة قراءة فقط، وزر تجهيز الطلب منفصل، والتنفيذ يتم عبر المسار الحوْكمي بعد مراجعة بشرية.

## القبول

اختبار عقد الواجهة، اختبار عدم إنشاء المخرج، واختبار عدم تطابق hash: ناجحة.
