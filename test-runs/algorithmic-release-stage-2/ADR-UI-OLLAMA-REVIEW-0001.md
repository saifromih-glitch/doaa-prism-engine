# ADR-UI-OLLAMA-REVIEW-0001

## القرار

اعتماد نافذة Tkinter تعرض الاستجابة الخام غير الموثوقة من Ollama وتوفر قرارين فقط: الرفض، أو القبول للبوابة فقط. لا يوجد زر تنفيذ مباشر.

## الضوابط

القرار الافتراضي هو الرفض. كل نتيجة تحمل execution_authority=none وautomatic_execution=false وexecution_started=false. المدخل الناقص أو القرار غير المعروف يُرفض. النافذة لا تعدّل المصدر ولا تكتب الملفات.

## الدليل

نجحت ثلاث حالات اختبار لقرار القبول للبوابة، والرفض، والقرار غير المعروف.
