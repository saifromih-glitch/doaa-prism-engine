# ADR-MODEL-MEDIATION-0001

## العنوان

وساطة محلية موحدة للنموذج داخل Doaa.

## القرار

يمر المسار من الاسترجاع الحتمي إلى مرحلة النموذج عند الحاجة ثم الإصلاح والبوابة والمراجعة البشرية والتنفيذ الآمن. النموذج يقترح فقط، ومخرجه بيانات غير موثوقة وغير تنفيذية.

## حدود السلطة

execution_authority يساوي none وautomatic_execution يساوي false دائمًا. لا كتابة للمصدر أو المخرج، ولا أوامر أو عمليات فرعية أو شبكة أو أسرار أو كود مولد أو نشر.

## معيار القبول

لا يُربط الوسيط بمنفذ تنفيذي إلا بعد اختبار cache hit دون استدعاء النموذج، وcache miss كمخرج غير تنفيذي، ورفض المحتوى التنفيذي، وعدم إنشاء الملفات، والمرور عبر المراجعة البشرية.
