# ADR-UNICODE-XLSX-EXECUTION-0001

## العنوان

اعتماد منفذ XLSX محدود لتطبيع محرفي Unicode المحددين.

## القرار

يُسمح للعملية `normalize_unicode_whitespace` بتحويل `U+00A0` و`U+202F` إلى `U+0020` فقط داخل عمود معلن في ورقة عمل معلنة. يتطلب التنفيذ معاينة سابقة مرتبطة بـ SHA-256، موافقة بشرية، hash للاقتراح، وhash لسجل التدقيق.

## الحماية

يُكتب ملف XLSX جديد فقط، ولا يُستبدل المصدر. تُحفظ الصفوف والخلايا غير المستهدفة، ويُرفض المحتوى غير النصي أو الورقة غير الفريدة أو العقد غير المطابق. لا ينفذ النموذج كودًا، ولا توجد شبكة أو أسرار أو عمليات فرعية.

## الدليل

اختبار مستقل ناجح للعربية وUnicode وUTF-8، وحارس hash المعاينة، وبوابة المراجعة، وعدم تعديل المصدر.

## الحدود

لا يشمل القرار التطبيع العام أو أي محرف Unicode آخر أو عمليات XLSX غير المذكورة في العقد.
