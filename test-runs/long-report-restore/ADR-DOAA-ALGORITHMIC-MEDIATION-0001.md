# ADR-DOAA-ALGORITHMIC-MEDIATION-0001

## القرار

اعتماد `doaa.alg.v1` كبروتوكول وسيط بين المستخدم أو الوكيل والنموذج. يحمل البروتوكول هوية الطلب والخوارزمية والإصدار والمعلمات والسياق والمدخل وسياسة الإخراج، ثم يعيد نتيجة مرتبطة بنفس الهوية.

## السبب

الهدف الأصلي لدعاء هو تقليل تكرار المطالبات والتوكنات عبر تمثيل خوارزمي قابل لإعادة الاستخدام، ثم ترجمة النتيجة إلى لغة طبيعية. المكونات القديمة تبدأ من proposal خاص بتحويل الملفات، لذلك تُحفظ كطبقة حوكمة وتنفيذ منفصلة.

## الحدود

النموذج اقتراح فقط. لا توجد في النسخة الأولى أدوات أو تنفيذ وكيل أو تحديث أوزان أو تحديث ذاتي أو نشر أو إرسال خارجي. كل الرسائل تعلن `execution_authority: none` و`automatic_execution: false`. الرموز غير المسجلة والحقول الزائدة والرسائل غير المرتبطة تُرفض رفضًا مغلقًا.

## القياس

لا يُفترض أن التمثيل الخوارزمي يوفر توكنات في كل حالة. يجب قياسه مقابل المطالبة الطبيعية وقياس الجودة ومعدل الرفض وإعادة الاستخدام قبل اعتماد ادعاء توفير عام.

## القبول

يُقبل القرار عند نجاح اختبارات العقد والنواة والوسيط والتقطير والقياس والواجهة، ثم القبول الكامل وفحص manifest والاستعادة النظيفة.
