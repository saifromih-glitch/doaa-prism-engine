# مراجعة الفجوة بين دعاء الحالي والهدف الأصلي

## حالة المرحلة

المرحلة: إعادة بناء خط الأساس والهدف الأصلي.

الهدف المعتمد: بناء دعاء كوسيط لغوي-خوارزمي بين المستخدم أو الوكيل الذكي والنموذج اللغوي، يحول المطالبة الطبيعية إلى تمثيل خوارزمي مضغوط، ويرسل التمثيل إلى النموذج، ثم يتحقق من النتيجة ويفكها إلى لغة طبيعية. الغرض هو تقليل التوكنات، تقليل تكرار المطالبات، وإعادة استخدام الخوارزميات دون تحديث ذاتي أو تنفيذ غير محكوم.

## الحقائق المثبتة

| المكوّن الحالي | الدليل | التقييم بالنسبة للهدف الأصلي |
|---|---|---|
| سجل خوارزميات محلي append-only | `doaa_algorithm_registry.py` و`ADR-ALGORITHM-REGISTRY-0001.md` | جزء قابل لإعادة الاستخدام؛ لكنه يعتمد على proposal منظم موجود مسبقًا ويستخدم مطابقة تامة فقط. |
| استرجاع حتمي قبل النموذج | `doaa_deterministic_retrieval.py` | يوفر cache hit/miss ويمنع استدعاء النموذج عند التطابق؛ لكنه لا يحول اللغة الطبيعية إلى رمز. |
| موجه pre-model | `doaa_premodel_router.py` | يفصل إعادة الاستخدام عن مرحلة النموذج؛ لكنه يستقبل proposal منظمًا، لا مطالبة طبيعية. |
| وساطة النموذج | `doaa_model_mediation.py` | يتحقق من envelope وبعض الحقول التنفيذية؛ لكنه يصنف proposal ولا يملك بروتوكول خوارزمي كاملًا أو فك نتيجة. |
| حوكمة التنفيذ | عقود واختبارات CSV/XLSX وسجل التدقيق | طبقة قوية يمكن الاحتفاظ بها كحاجز ثقة، لكنها ليست الوسيط اللغوي العام المطلوب. |
| Ollama المحلي | `doaa_ollama_proposal_adapter.py` | مصدر اقتراح خام محلي يمكن عزله خلف البروتوكول؛ لا يجب اعتباره مترجمًا أو صاحب قرار. |
| قياس التوكن | لا يوجد مسار مكتمل للقياس المقارن | فجوة مباشرة يجب بناؤها قبل إعلان التوفير. |
| فك الإجابة وترجمتها | لا يوجد عقد مستقل مكتمل للنتيجة الخوارزمية | فجوة مباشرة. |
| تقطير الخوارزميات | لا توجد آلية مكتملة لاكتشاف التكرار وإصدار اقتراح تقطير | فجوة مباشرة، ويجب أن تبقى اقتراحية ومراجعة بشريًا. |

## ما بُني ويمكن الاحتفاظ به

يُعاد استخدام سجل الخوارزميات، الاسترجاع الحتمي، العزل بين مراحل النموذج والتنفيذ، العقود الصارمة، الفشل المغلق، سجل التدقيق، بصمات الهوية، واختبارات السلامة الساكنة. هذه مكونات حوكمة وذاكرة تشغيلية مناسبة للطبقة الجديدة.

## ما لم يُبنَ بعد

لم يُبنَ بعد بروتوكول موحد يحمل رمز الخوارزمية وإصدارها ومعلماتها وسياقها المختصر. لم يُبنَ محول حتمي أو محكوم ينقل مطالبة طبيعية إلى رمز معتمد. لم يُبنَ عقد نتيجة يضمن أن إجابة النموذج مرتبطة بالطلب والخوارزمية ويمكن فكها. لم يُبنَ مسار قياس يقارن التمثيل المضغوط بالمطالبة الطبيعية. ولم تُبنَ آلية تقطير مقيدة تحول التكرار إلى اقتراح خوارزمية جديد دون إدخال تلقائي.

## الفجوة المعمارية الأساسية

النظام الحالي يبدأ من `proposal` منظم خاص بتحويل الملفات. الهدف الأصلي يبدأ من مطالبة طبيعية عامة أو شبه عامة ثم يحتاج إلى تصنيف أو ترميز خوارزمي. لذلك لا يجوز اعتبار `doaa_local.py` هو الوسيط النهائي، ولا يجوز توسيعه عشوائيًا ليصبح وسيطًا عامًا. يجب بناء طبقة mediation مستقلة ذات عقد خاص، ثم ربطها بالحوكمة الحالية عبر واجهة واضحة.

## القرار المقترح

اعتماد بنية طبقية جديدة فوق المكونات الحالية:

```text
Natural Request
  -> Deterministic/Proposal Classifier
  -> Algorithm Message Contract
  -> Pre-model Retrieval
  -> Model Adapter (raw, untrusted)
  -> Result Contract Validator
  -> Natural-language Renderer
  -> Audit and Metrics
```

يُبنى أولًا نطاق تجريبي بثلاث خوارزميات غير تنفيذية: تلخيص، تركيب إجابة، وتخطيط خطوات. لا يدخل الوكيل أو tool calling أو التنفيذ الخارجي في هذا النطاق.

## المخاطر المفتوحة

التوفير النظري في التوكن لا يثبت فائدة عملية ما لم تُقارن المطالبات على مجموعة ذهبية. الضغط الزائد قد يحذف سياقًا ضروريًا. التحويل من لغة طبيعية إلى رمز قد يخطئ في النية. والتقطير قد يثبت تعميمًا غير صحيح إذا لم يرتبط بأمثلة واختبارات ومراجعة بشرية.

## ما لم يُختبر

لم يُختبر بعد تحويل طبيعي عربي إلى رسالة خوارزمية، أو إرسال الرسالة إلى نموذج ثم فك النتيجة، أو قياس التوفير والجودة على حالات متكررة، أو رفض نتيجة نموذج غير مطابقة لعقد النتيجة. كما أن تشغيل مجموعة الاختبارات الكاملة في هذه الجلسة لم يكتمل بسبب وجود اختبارات script-style ومجلدات release تستدعي مساراتها الخاصة؛ وقد تم عزل فشل Excel وتشخيص إصلاح UTF-8، لكن القبول الكامل بعد هذا التعديل يحتاج تشغيلًا منفصلًا صحيحًا.

## الخطوة التالية الوحيدة

تجميد عقد `doaa.alg.v1` لرسالة الطلب الخوارزمية وعقد `doaa.result.v1` لنتيجة النموذج، مع حالات القبول والرفض وحدود الحجم والعمق والسلطة.
